# elinstyle

قالب فارسی فروشگاه پوشاک زنانه و مردانه، با طراحی RTL و دارایی‌های محلی.

## ساختار

- `design/`: تصاویر UI، هویت بصری، توکن‌ها و منابع طراحی.
- `html/`: نسخهٔ مستقل HTML/CSS/JavaScript و راهنمای اجرای محلی.
- `wordpress/themes/elinstyle/`: قالب وردپرس.
- `wordpress/plugins/`: افزونهٔ همراه اختصاصی.
- `demos/`: محتوای دموها؛ گوتنبرگ ابتدا، المنتور پس از تأیید گوتنبرگ.
- `docs/design/`، `docs/frontend/` و `docs/wordpress/`: مشخصات و شواهد تحویل هر نقش.
- `docs/project/`: تصمیم‌ها و وضعیت هماهنگی.
- `tools/`: ابزار مشترک ثبت و ارسال تغییرات هر نقش.

## وضعیت

ریپو برای جمع‌آوری خروجی‌های در حال توسعه است؛ وجود فایل یا commit به‌معنای تأیید نهایی و آماده‌بودن انتشار محصول نیست. راهنمای نصب و محدودیت‌های واقعی هر مرحله در مستندات همان بخش ثبت می‌شود. نسخهٔ گوتنبرگ مقدم است و المنتور تا تأیید آن آغاز نمی‌شود. حداقل PHP هدف 7.4 است؛ نسخه‌ها و آزمون‌های واقعی در docs/wordpress ثبت شوند.

## همکاری

هر نقش فقط خروجی نهایی مرحلهٔ خودش را در مسیرهای تعیین‌شده همگام کند و از tools/Publish-Template.ps1 استفاده کند. ابتدا Preview و سپس Push؛ شاخهٔ مشترک را عوض نکنید، تغییرات دیگران را برنگردانید و Git دستی موازی اجرا نکنید. manifest ریشه، مسیرهای مجاز هر نقش را مشخص می‌کند.

```powershell
.\tools\Publish-Template.ps1 -Repository . -Role frontend -Action Push -Message "Update frontend delivery"
```

## دارایی‌ها و مجوز

ریپو در شروع خصوصی است. فونت‌ها و دارایی‌های خریداری‌شده تا بررسی مجوز بازتوزیع برای انتشار عمومی مجاز فرض نمی‌شوند؛ عمومی‌کردن ریپو نیازمند تصمیم جداگانه است. فایل Elementor Pro، کلیدها، اطلاعات ورود، پایگاه‌داده، سفارش‌ها و اطلاعات مشتری داخل ریپو قرار نگیرند. این ریپو مجوز متن‌باز اعطا نمی‌کند؛ مجوز توزیع کد و دارایی‌ها باید مستقلاً تعیین شود.
