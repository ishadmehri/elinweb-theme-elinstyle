# چیدمان‌های گوتنبرگ

قالب و Companion و Woo باید فعال باشند. فایل‌های account.html، cart.html، checkout.html و product.html را در ویرایشگر کد یک برگه/بخش متناظر درج کنید؛ سپس به ویرایشگر دیداری برگردید. این‌ها بلوک‌های واقعی و پویا هستند و مشتری، سفارش، رمز یا دادهٔ fixture وارد نمی‌کنند. برگه‌ها را در تنظیمات Woo نسبت دهید؛ product چیدمان محصول است و داده از زمینهٔ محصول واقعی می‌آید.

برای پنج صفحه و سربرگ/پابرگ، ابزار صریح «دموی الین‌استایل» در Companion، الگوهای ثبت‌شدهٔ `wordpress/themes/elinstyle/patterns` را با لینک‌ها و رسانهٔ محیط فعلی می‌خواند. نسخهٔ PHP الگوها باید در زمینهٔ WordPress اجرا شود؛ PHP را در core/html نچسبانید. هیچ dump یا نصب کامل WordPress لازم نیست. Elementor آماده/منتشر نشده است.
