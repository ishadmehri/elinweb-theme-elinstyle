# Elementor classic demo 0.4.0

از «نمایش ← الین‌استایل» در Companion وارد کنید. منبع دادهٔ ۱۴ سند در wordpress/plugins/elinstyle-companion/demo-content/elementor-0.4.0.json قرار دارد؛ شناسه/نشانی سایت هنگام ورود با APIهای WordPress و Elementor ساخته می‌شوند. این JSON بستهٔ دادهٔ درون‌ریز همراه است. Core/Pro و Woo در بسته توزیع نمی‌شوند.

راهنمای نصب/ویرایش: docs/wordpress/elementor-and-importer.md؛ نگاشت ویجت/CSS: docs/wordpress/elementor-widget-map.json. kit فقط با انتخاب جداگانهٔ کاربر فعال می‌شود. Products اصلی Pro برای خانه و elinstyle-catalog برای faceted shop استفاده می‌شوند.

برای بازسازی bundle، BeautifulSoup4 نصب و ELINSTYLE_REFERENCE_DIR را به مرجع HTML تأییدشده تنظیم و build-elementor.py را اجرا کنید. مولد فایل مرجع را تغییر نمی‌دهد.
