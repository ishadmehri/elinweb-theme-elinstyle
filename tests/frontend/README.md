# آزمون فرانت‌اند

پیش‌فرض همهٔ اسکریپت‌ها `../../html` است. Node و Playwright لازم‌اند؛ اجرای خود HTML به آن‌ها نیاز ندارد.

```powershell
cd tests/frontend
npm install
npx playwright install chromium
npm run smoke
npm run verify
```

با `ELINSTYLE_BROWSER` می‌توان مسیر مرورگر نصب‌شده، با `ELINSTYLE_ROOT` مقصد HTML دیگر و با `ELINSTYLE_OUTPUT` مسیر خروجی QA را تعیین کرد. پیش‌فرض خروجی `output/` است؛ این پوشه و `node_modules/` در همین محدوده نادیده گرفته می‌شوند. هیچ dependency یا cache در commit نیست.

آزمون smoke هر ده صفحه در عرض ۱۴۴۰ و ۳۹۰، منابع محلی، فونت، مسیر حساب هدر/منو، خطاهای اجرا، نبود درخواست خارجی، سرریز و SHA-256 فایل‌های runtime را بررسی می‌کند. آزمون‌های تکمیلی محصول، سبد/تسویه، ورود/حساب، حالت‌های مرزی، تعاملات، موشن و راهنمای اندازه از تحویل آزموده‌شده منتقل شده‌اند؛ تنها مسیر پیش‌فرض HTML، مرورگر و مسیر نوشتن خروجی برای ساختار ریپو تطبیق یافته‌اند. داده‌ها و رمزهای داخل آزمون کاملاً ساختگی‌اند.

`evidence/source-*` گزارش‌های منتخب تحویل قبلی‌اند. `evidence/repository-smoke-report.json` و `evidence/repository-regression-summary.json` نتیجهٔ اجرای نسخهٔ داخل ریپو هستند. تصاویر تکراری و خروجی موقت QA commit نشده‌اند؛ اسکریپت‌ها آن‌ها را هنگام اجرا در output تولید می‌کنند. گزارش‌ها اثبات ورود، پرداخت یا عملکرد سرور واقعی نیستند.
