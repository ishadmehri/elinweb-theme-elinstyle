# موشن‌های الین‌استایل

پیاده‌سازی محلی با CSS و Web Animations API؛ بدون وابستگی یا درخواست شبکه. `motion.js` پیش از `size-guide.js` و `app.js` در هر پنج HTML بارگذاری می‌شود.

- ورود پاپ‌آپ‌ها: ۲۴۰ میلی‌ثانیه، opacity و جابه‌جایی عمودی حداکثر ۸ پیکسل؛ خروج: ۲۲۰ میلی‌ثانیه و حداکثر ۶ پیکسل. پس‌زمینه نیز fade می‌شود. Escape، بستن و کلیک بیرون راهنمای اندازه از همان چرخه استفاده می‌کنند.
- تب منتخب‌های خانه، جدول زنانه/مردانه و نتایج فیلتر: ۱۸۰ میلی‌ثانیه، opacity از ۰٫۶۵ و جابه‌جایی ۳ پیکسل. داده، تعداد و empty state فوراً اعمال می‌شوند؛ ارتفاع و چیدمان انیمیشن ندارند.
- دکمه‌ها و وضعیت تب‌ها: گذار رنگ/پس‌زمینهٔ ۱۸۰ میلی‌ثانیه. فقط روی دستگاه دارای hover و اشاره‌گر دقیق، کارت ۲ پیکسل و دکمهٔ اصلی ۱ پیکسل بالا می‌رود؛ سایهٔ کارت بسیار کم است. focus-visible حفظ شده است.
- هر عنصر فقط یک انیمیشن JS فعال دارد؛ تغییر جدید انیمیشن قبلی را لغو می‌کند و صف یا تأخیر مصنوعی ندارد. خروج پاپ‌آپ تا پایان حرکت، وضعیت modal و قفل اسکرول را حفظ می‌کند؛ بازکردن دوباره خروج قبلی را لغو می‌کند. پس از بسته‌شدن، فوکوس و overflow قبلی برمی‌گردند.
- با `prefers-reduced-motion: reduce` گذارها و حرکت‌های تزئینی خاموش‌اند. تغییر این ترجیح هنگام اجرا نیز انیمیشن جاری را لغو می‌کند و اگر پاپ‌آپ در حال خروج باشد، بستن را فوراً تکمیل می‌کند.

آزمون `qa/motion-check.cjs`: هر پنج صفحه با file:// در دسکتاپ ۱۴۴۰ و موبایل ۳۹۰، با ترجیح معمولی و کاهش حرکت (۲۰ ترکیب). تغییرهای سریع پاپ‌آپ/تب/فیلتر، شمارش و empty state، بازیابی فوکوس، قفل/آزادسازی اسکرول، هاور ماوس، نبود حرکت در موبایل/کاهش حرکت، تغییر زندهٔ ترجیح، خطاهای JS و درخواست خارجی کنترل شدند. گزارش‌ها: `qa/motion-report-staging.json` و `qa/motion-report-final.json`.

فایل‌های محصول تغییرکرده: `motion.js` جدید؛ `styles.css`، `size-guide.js`، `app.js` و پنج HTML برای اتصال اسکریپت. ظاهر نهایی ثابت و محتوای تأییدشده حفظ شده‌اند؛ فایل برند و صفحهٔ جدیدی تغییر یا اضافه نشده است.
