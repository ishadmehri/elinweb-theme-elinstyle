# تحویل فرانت‌اند elinstyle

بستهٔ منتقل‌شده در 2026-11-15 شامل ده صفحهٔ کامل و آزموده‌شدهٔ استاتیک است. منابع نهایی و staging پیش از کپی مقایسه شدند و ۳۲ فایل اجرایی HTML/CSS/JS و assets یکسان بودند. منبع اصلی تغییر یا حذف نشد؛ `source-manifest.json` هش و اندازهٔ دقیق فایل‌های کپی‌شده را ثبت می‌کند.

تحویل حساب، محصول و سبد/تسویه کاملِ محدودهٔ Frontend است. ورود واقعی، ثبت‌نام، ایمیل، مالکیت سفارش، ذخیرهٔ نشانی و جزئیات، درگاه، سفارش و پرداخت سرور پیاده‌سازی این بسته نیستند. حساب «کاربر نمونه» و سفارش ۱۰۴۲ fixture است؛ این خروجی محصول آمادهٔ انتشار عمومی یا اتصال تکمیل‌شدهٔ WordPress معرفی نمی‌شود.

فقط `html/`، `docs/frontend/` و `tests/frontend/` مالکیت این تحویل‌اند. فایل‌های ریشه، WordPress، design و demos تغییر داده نشده‌اند. منابع طراحی موجود در خروجی قدیمی، فایل‌های مولد/پیش‌نمایش برند، تصاویر تکراری QA، node_modules، cache، لاگ، محیط محرمانه و پایگاه‌داده خارج از این تحویل‌اند. چهار SVG مورد استفاده، سه فایل فونت و دو تصویر لازم برای عملکرد محلی همراه HTML هستند.

ریپوی مقصد پیش از انتشار با GitHub خصوصی تأیید شد. فونت‌های Yekan Bakh خریداری‌شده‌اند؛ کپی در ریپوی خصوصی مجوز عمومی یا بازتوزیع ایجاد نمی‌کند و مجوز دارایی‌ها پیش از توزیع باید بررسی شود. هیچ token، credential یا .env واقعی در بسته قرار ندارد. اطلاعات فرم و fixtureها نمونه‌اند. هویت توسعه‌دهندهٔ عمومی پروژه با اطلاعات ورود یا دادهٔ مشتری اشتباه نشود.

شواهد این انتقال در `tests/frontend/evidence/repository-smoke-report.json` و `repository-regression-summary.json` ثبت می‌شوند؛ نتایج تاریخی منتخب همان پوشه provenance تحویل اولیه را حفظ می‌کنند. آزمون سرور یا صفحه‌خوان در این بسته ادعا نمی‌شود.

بررسی انتقال 2026-11-15: هر ۹ گروه آزمون روی html داخل ریپو گذشت؛ smoke هر ده صفحه را در دو عرض (۲۰ بارگذاری) با فونت محلی واقعاً بارگذاری‌شده، بدون سرریز، خطای اجرا، درخواست خارجی یا بارگذاری ناموفق بررسی کرد. SHA-256 هر ۳۲ فایل runtime پس از آزمون نیز با هر دو منبع اصلی برابر ماند و لینک‌های Markdown بسته بررسی شدند.
