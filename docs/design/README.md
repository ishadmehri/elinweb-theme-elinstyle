# تحویل طراحی elinstyle

تاریخ انتشار بسته: 2026-11-15. این بسته فقط طراحی الین‌استایل را در ریپوی خصوصی مشترک نگه می‌دارد؛ انتشار ریپو تأیید تازهٔ صفحه نیست.

- [وضعیت تأیید صفحات](approvals.md)
- [روش بازتولید](reproduce.md)
- [مجوز و منابع فونت/تصاویر](LICENSE-NOTES.md)
- مشخصات اصلی و نقشهٔ تاریخی صفحات: `specs/`
- پیش‌نمایش‌های نهایی: `../../design/previews/`
- منابع قابل ویرایش: `../../design/source/artboards/`
- لوگو و نشانه: `../../design/brand/`
- توکن‌های جاری و نسخهٔ تاریخی: `../../design/tokens/`

PNGهای صفحات بدون تغییر از خروجی موجود کپی شده‌اند. طرح‌های قدیمی خانه، فروشگاه، مقاله، دسته‌بندی، درباره و تماس ممکن است نام موقت «روزپوش» را نشان دهند؛ نام نهایی قالب elinstyle است. این نام تاریخی بدون دستکاری طرح مصوب حفظ شده و لوگو و توکن جاری جدا ارائه شده‌اند.

مشخصات اصلی برای سابقه عیناً نگه داشته شده‌اند و ممکن است وضعیت قدیمی «منتظر تأیید» یا مسیرهای دستگاه طراح را ذکر کنند؛ وضعیت جاری این تحویل را فقط از approvals.md بخوانید. مسیرهای ورودی/خروجی در کپی اسکریپت‌های بازتولید برای ساختار ریپو تطبیق داده شده‌اند؛ منابع اصلی حذف یا تغییر نکرده‌اند.

راهنمای اندازه: دو PNG با پسوند implementation-reference تصویر مرجع اجرای مؤلفهٔ تأییدشده از QA فرانت‌اند هستند، نه بوم SVG طراحی تازه. کد آن مؤلفه و شواهد تعاملی در مالکیت نقش فرانت‌اند است.
