- در 2026-11-15 طبق درخواست صریح کاربر «ریپو رو پابلیک بذار»، دسترسی ریپو به PUBLIC تغییر کرد.
- مقصد: https://github.com/ishadmehri/elinweb-theme-elinstyle

- عبارت خصوصی‌بودن در اسناد تحویل قبلی، مربوط به زمان آن تحویل است؛ وضعیت جاری همین سند است.
- این تغییر دسترسی، لایسنس تازه‌ای برای کد، فونت‌ها یا دارایی‌های ثالث انتخاب نمی‌کند.
