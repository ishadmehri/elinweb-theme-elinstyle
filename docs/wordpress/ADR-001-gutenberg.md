# ADR-001 — قالب ترکیبی با الگوهای گوتنبرگ

وضعیت: اجراشده برای دموی گوتنبرگ؛ تأیید بصری کاربر در انتظار.

## مسئله و تصمیم

مرجع، HTML پنج صفحه و دارایی‌های محلی تأییدشده است. پوستهٔ PHP استاندارد برای سربرگ/پابرگ و مسیرهای Woo، همراه theme.json نسخهٔ ۳ و الگوهای بلوکی انتخاب شد. این یک قالب کلاسیک مجهز به بلوک است؛ Site Editor کامل ادعا نمی‌شود. ویرایش صفحات در Post Editor و ویرایش بخش‌های مشترک در reusable blocks انجام می‌شود.

بلوک‌های Group، Heading، Paragraph و Image هسته اولویت دارند. `block-map.json` شمارش دقیق را ثبت می‌کند. بلوک اختصاصی catalog برای query واقعی Woo و HTML کارت مطابق طراحی است؛ چندپارگی منطق فیلتر در JS حذف شد. contact پیش‌نمایش صریح غیرارسالی است. fragment تنها برای ساختارهای کوچک فاقد معادل مستقیمِ حافظ HTML، از جمله SVG، کنترل‌های تعاملی، لینک کارت ترکیبی و جدول/فهرست نگه داشته شد؛ برای تمام صفحه یا متن اصلی به‌کار نرود. پیش‌نمایش تصویری و نوار جانبی HTML دارد؛ حدود ویرایش فنی آن روشن است.

CSS مرجع پس از محدودشدن به `.elinstyle-surface` از enqueue_block_assets در فرانت و iframe مشترک است. add_editor_style فقط اصلاحات بوم را می‌آورد. فونت و مقادیر رنگ/فاصله در theme.json نیز ارائه شده‌اند؛ اسکریپت تعاملی در ویرایشگر اجرا نمی‌شود.

## پیامدها و مصالحه‌ها

- DOM گروه/تصویر تغییر حداقلی دارد؛ اصلاحات در assets/blocks.css ثبت شده‌اند. متن مستقیم داخل Group به Paragraph با display:contents تبدیل شد تا ذخیره معتبر بماند.
- سربرگ/پابرگ به صورت wp_block ذخیره و در shell رندر می‌شوند؛ تعویض قالب داده را حذف نمی‌کند.
- Woo و Companion مسئول داده و منطق‌اند؛ هیچ فایل هسته یا افزونهٔ ثالث تغییر نکرده است.
- فیلتر زندهٔ نمایشی استاتیک به فرم GET واقعی تبدیل شده است؛ به‌جای وانمودکردن خرید، لینک محصول به endpoint واقعی Woo می‌رود. UI فیلتر نیاز به بررسی بصری کاربر دارد.
- اجرای Elementor، Elementor Pro و ویجت‌های غیراتمیک فقط پس از تأیید این مرحله تصمیم اجرایی بعدی است.
- لایسنس مستقل هنوز باز است؛ از نقش‌های مرجع یا وابستگی‌های ابزارها به محصول نسبت داده نمی‌شود.
