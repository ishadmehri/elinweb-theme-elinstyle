# ADR-004 — المنتور کلاسیک و ورود انتخابی

2026-11-16؛ اجراشده در 0.4.0. دستور جدید کاربر شروع المنتور را مجاز کرد؛ شرط تاریخی انتظار تأیید جداگانهٔ گوتنبرگ دیگر مانع شروع این مرحله نیست.

هر دمو اسناد مستقل دارد و صفحه بین ویرایشگرها تبدیل نمی‌شود. واردکننده از Documents API بومی برای wp-page/header/footer/product/popup/kit استفاده می‌کند. Containers و ویجت‌های کلاسیک Elementor/Pro مقدم‌اند؛ HTML/shortcode تمام‌صفحه و Atomic/e-* در bundle نیستند.

Products اصلی چندفیلتر هم‌زمان، chip، اسلایدر، URL/history و fallback سرور موردنیاز را پوشش نمی‌دهد؛ تنها ویجت اختصاصی همین کاتالوگ در Companion با کنترل‌های UI و CSS محدود است. خانه Products اصلی دارد.

CSS گوتنبرگ در محدودهٔ خودش باقی است. رنگ، قلم و فاصلهٔ المنتور با تنظیمات اصلی ذخیره می‌شوند. نیازهای فاقد کنترل در widget Custom CSS و skip-link خارج محتوا در kit هستند. native Woo widgets در فرانت و refresh از template family یکسان استفاده می‌کنند؛ اسکریپت فرم گوتنبرگ در صفحات المنتور بارگذاری نمی‌شود.

ساخت محتوا از انتخاب انتساب‌ها جداست. journal/ownership/fingerprint backup کامل یا تراکنش اتمیک چندجدولی نیست؛ checkpointها ادامه و rollback محدود را ممکن می‌کنند. هیچ سفارش/محصول نمونه در ورود عادی ساخته نمی‌شود.

DOM فرم‌ها، انتخاب تنوع و کارت‌های Pro با HTML نمایشی یکسان نیست. ساختار، دارایی، رنگ و قلم هماهنگ می‌شوند؛ برابری پیکسلی تمام صفحات ادعا نمی‌شود. جدول اندازه در موبایل از accordion کلاسیک Tabs استفاده می‌کند.
