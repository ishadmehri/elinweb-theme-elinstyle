سورس قالب/Companion حداقل PHP7.4/WP6.6 دارد؛ بستهٔ المنتور عمداً Core+Pro4.3.3/WP6.8 را حداقل می‌گیرد. Woo10.8 header خودش WP6.9/PHP7.4 را می‌خواهد. آزمون runtime نهایی PHP8.2.29 است؛ syntax7.4 تضمین runtime کامل وابستگی‌ها روی7.4 نیست.

آزمون Site Settings یک بار هنگام جابه‌جایی سریع سند پیش از تکمیل بارگذاری chunkهای ویرایشگر خطا داد؛ با انتظار readiness بومی و اجرای مستقل دوباره گذشت. تست نصب کاملاً خالی، باقی‌ماندن نوع‌های داخلی الگوی المنتور پس از rollback را آشکار کرد؛ ثبت مالکیت و حفاظت از مصرف خارجی برای آن‌ها اضافه و روی پایگاه‌دادهٔ خالی دوباره آزموده شد. رفتار UI واقعی واردکننده جداگانه آزموده شد. خطاهای دریافت خودکار به‌روزرسانی در محیطی با اینترنت مسدود و پیام اولیهٔ bootstrap ترجمه/جدول Notes فروشنده، ادعای «کل log بدون هشدار» را نامعتبر می‌کنند؛ چنین ادعایی نداریم.

محدودیت‌ها: پیکسل‌به‌پیکسل تمام DOM بومی Pro با HTML برابر نیست؛ PHP7.4 runtime کامل0.4، MariaDB، مرورگر Safari، خوانشگر صفحه، PHPCS/WPCS، انتقال وجه، تحویل ایمیل بیرونی، اصالت مجوز/توزیع Pro نزد فروشنده و تمرین بازیابی backup آزموده نشده‌اند. Pro استفاده‌شده توزیع محلی مجازشده توسط کاربر است؛ header/API محلی اثبات اعتبار مجوز نزد فروشنده نیست. دو سفارش QA پرداخت‌نشده با دادهٔ ساختگی فقط در نصب جدا ساخته شدند؛ سفارش‌های سایت قبلی تغییر نکردند.

گزارش‌های evidence در tests/wordpress/evidence/0.4.0 خلاصهٔ پاک از config، cookie، token، backup و پایگاه‌داده‌اند. تصاویر اصلی/مقایسه‌ای منتخب در همان پوشه‌اند. برای بازتولید، راهنمای tests/wordpress خوانده شود.
