# Elinstyle WordPress — 0.3.0

سورس قابل نصب نسخهٔ گوتنبرگ/هیبرید در `wordpress/themes/elinstyle` و افزونه در `wordpress/plugins/elinstyle-companion` است. توسعه‌دهندهٔ افزونه Iman Shadmehri، https://elinweb.ir است. ریپو خصوصی و مجوز پروژه همچنان در انتظار انتخاب است؛ مجوز تازه‌ای اعمال نشده. Elementor تا تأیید صریح نسخهٔ گوتنبرگ اجرا نشده است. حقوق بازتوزیع فونت و تصاویر پیش از انتشار عمومی باید تعیین شود.

## نصب و ویرایش

پوشهٔ قالب و افزونه را در wp-content متناظر کپی و هر دو را فعال کنید؛ WooCommerce سازگار را جداگانه نصب کنید. کد Woo/WordPress و vendor ابزار در ریپو نیست. PHP حداقل7.4؛ ترکیب واقعاً تست‌شده WP7.1.4 / Woo10.8.0 / PHP8.2.29 / MySQL8.4.0 است؛ تمام34 PHP پروژه با PHP7.4.30 lint شدند. runtime کامل0.3.0 با7.4 جداگانه اجرا نشده است.

از ابزارها ← دموی الین‌استایل، ورود صریح دمو را در نصب محلی خالی اجرا کنید؛ فعال‌سازی به‌تنهایی محتوا نمی‌سازد. پنج صفحه و بخش‌های مشترک از الگوهای خود قالب تولید می‌شوند و محتوای موجود خودکار بازنویسی نمی‌شود. ورود به این ابزار capability و nonce دارد. تصاویر و لینک‌های الگو در محیط جدید با API وردپرس ساخته می‌شوند؛ dump یا شناسه‌های مشتری محلی وارد نمی‌شود.

الگوهای محصول، سبد، پرداخت و حساب در قالب ثبت شده‌اند؛ `demos/gutenberg` برای چهار چیدمان مستقل، markup بلوکی قابل درج در ویرایشگر کد دارد. سبد/پرداخت/حساب را به برگه‌های متناظر تنظیمات پیشرفتهٔ Woo نسبت دهید. برگهٔ اختیاری login با الگوی حساب، کاربر واردشده را به حساب می‌برد. داده و موجودی محصول از Woo، حساب/سفارش از کاربر احرازشده و سیاست‌های ثبت‌نام/ارسال/مالیات/درگاه از تنظیم واقعی فروشگاه است. ورود عمومی دمو محصولات و سفارش‌های QA نمی‌سازد.

در تحویل محلی، /login/ و /my-account/ و زیرمسیرهای بومی اجرا شدند. ورود username/email، خروج، بازیابی عمومی، بازنشانی توکن یک‌بارمصرف، سفارش متعلق به کاربر، نشانی/جزئیات حساب و گوتنبرگ تست شدند. ثبت‌نام همان تنظیم خاموش فروشگاه ماند؛ خرید مهمان روشن بود. تحویل واقعی ایمیل بیرونی و درگاه، ثبت‌نام فعال، صفحه‌خوان و PHPCS هنوز تست نشده‌اند. هیچ نشست یا سفارش ثابت دمو جای احراز هویت یا دادهٔ واقعی را نمی‌گیرد.

## آزمون و شواهد

از `tests/wordpress`، `npm install` و `npx playwright install chromium` را برای وابستگی آزمون انجام دهید. `npm run lint` با PHP_BINARY دلخواه و `npm run smoke` با WP_BASE_URL نصب خودتان اجرا می‌شوند. BROWSER_EXECUTABLE اختیاری است. آزمون smoke فقط خواندنی است. توضیح آزمون‌های توسعهٔ fixture در README همان پوشه آمده است.

`tests/wordpress/evidence/local-0.3.0.json` خلاصهٔ پاک‌سازی‌شدهٔ نتیجهٔ واقعی و `source-sha256.json` اثر انگشت سورس منتشرشده است. raw QA، تصویر حساب/سفارش، credential/token/cookie، پایگاه‌داده، لاگ و نصب Local و ZIP عمداً در ریپو نیستند. اسناد دیگر این پوشه تاریخچهٔ تحویل محلی و ADRها هستند؛ نام فایل‌های شواهد و مسیرهای Local در آن‌ها به سابقه اشاره می‌کند و الزاماً فایل منتشرشده نیست. مسیرهای ابزار قدیمی جای دستورهای همین راهنما را نمی‌گیرند.
