# Elinstyle 0.4.0

قالب فارسی RTL پوشاک با دو دموی مستقل گوتنبرگ و Elementor/Pro کلاسیک و مسیر خرید و حساب واقعی WooCommerce. فعال‌سازی قالب یا Companion به‌تنهایی محتوایی وارد نمی‌کند.

## نصب و انتخاب دمو

1. بسته‌های `elinstyle-0.4.0.zip` و `elinstyle-companion-0.4.0.zip` را از بخش پوسته‌ها و افزونه‌ها نصب و فعال کنید. WooCommerce فعال لازم است؛ زبان فارسی و پیوندهای یکتای «نام نوشته» برای دمو مناسب‌اند.
2. برای دموی المنتور، Elementor و Elementor Pro سازگار را از منبع مجاز خود نصب کنید. این دو افزونه داخل بسته نیستند. گوتنبرگ به آن‌ها وابسته نیست.
3. «نمایش ← الین‌استایل» را باز و کارت گوتنبرگ یا المنتور را انتخاب کنید. پیش‌نیازها و محتوای ورودی نمایش داده می‌شوند؛ دکمهٔ ورود فقط همان دمو را می‌سازد.
4. نتیجه پیوند مشاهده/ویرایش اسناد را نشان می‌دهد. نامک‌ها با `elin-gutenberg-040-` یا `elin-elementor-040-` شروع می‌شوند. ورود دوباره شناسه‌ها و ویرایش‌های کاربر را حفظ می‌کند.
5. در فرم جداگانهٔ انتخاب دمو، گزینه‌های دلخواهِ خانه، صفحات Woo، بخش‌های مشترک، منو و Site Settings را علامت بزنید و تأیید کنید. هیچ‌کدام صرفاً با ورود محتوا انتخاب نمی‌شوند. انتخاب می‌تواند انتساب فعلی همان گزینه را تغییر دهد؛ پیش از آن پشتیبان بگیرید.
6. محصولات، دسته‌ها، ویژگی‌ها، ارز، مالیات، ارسال، پرداخت و ایمیل را در Woo تنظیم کنید. درون‌ریز محصول، مشتری، سفارش، کوپن یا روش پرداخت نمونه نمی‌سازد و تنظیمات تجاری را تغییر نمی‌دهد.

گوتنبرگ ۹ برگه و ۴ بخش/الگو دارد. المنتور همین پوشش را با ۱۴ سند شامل ۹ برگه، هدر، فوتر، محصول، پاپ‌آپ اندازه و kit مستقل عرضه می‌کند. مقالهٔ نمونه برگهٔ قابل ویرایش است. [راهنمای درون‌ریزی و ویرایش](elementor-and-importer.md).

## ویرایش

متن، تصویر، دکمه، منو، فرم، ورود، محصول، سبد، پرداخت و حساب المنتور از ویجت‌های بومی کلاسیک استفاده می‌کنند؛ کل صفحه HTML یا shortcode نیست. تنها ویجت اختصاصی، کاتالوگ دارای فیلترهای Woo است. رنگ، قلم، فاصله و موبایل از کنترل‌های اصلی تغییر می‌کنند. CSS استثنایی در Custom CSS همان ویجت و CSS مشترک در Site Settings است. [نگاشت ویجت‌ها و CSS](elementor-widget-map.json).

گوتنبرگ متن/تصویر اصلی را در بلوک‌های هسته و کاتالوگ، خرید و حساب را در بلوک‌های پویا نگه می‌دارد؛ اجزای کوچک فاقد معادل مستقیم بلوک جزء نمایشی‌اند. انتخاب دموی دوم، صفحات قبلی یا ویرایشگر آن‌ها را تبدیل نمی‌کند.

فرم تماس المنتور بدون اقدام/گیرندهٔ ارسال وارد می‌شود؛ برای ارسال واقعی Action و گیرنده را در Form تنظیم کنید. فرم گوتنبرگ نمایشی است. جدول اندازه نمونه است و باید برای محصول فروشگاه جایگزین شود.

## نسخه‌ها و شواهد

آزمون 0.4.0: WordPress 7.1.4، PHP 8.2.29، MySQL 8.4، WooCommerce 10.8.0، Elementor/Core و Pro 4.3.3. حداقل کد اختصاصی PHP 7.4 و WP 6.6 است؛ بستهٔ المنتور Core/Pro 4.3.3 و WP 6.8+ می‌خواهد؛ Woo 10.8.0 طبق header خودش WP 6.9+ می‌خواهد. ترکیب نصب باید بالاترین حداقل وابستگی‌ها را رعایت کند؛ runtime نسخه‌های قدیمی‌تر برای 0.4.0 آزموده نشده است.

ذخیره/بازگشایی واقعی ویرایشگر، اثر کنترل‌ها در فرانت، Site Settings، نصب ZIP، تعارض، قفل، شکست/ادامه/بازگردانی و حفظ دموی اول آزموده شده‌اند. خرید محلی با موجودی، کوپن، ارسال و سفارش پرداخت‌نشده بررسی شده؛ انتقال وجه/ایمیل بیرونی آزموده نشده است. [ماتریس آزمون](compatibility.md) و [تطبیق بصری](elementor-visual-review.md).

Pro از توزیع محلی مجازشده توسط کاربر برای تست استفاده شده است. نسخه از header خوانده شد؛ اصالت توزیع یا اعتبار مجوز نزد فروشنده از این آزمون نتیجه نمی‌شود. درون‌ریز وضعیت مجوز را از API خود Pro می‌خواند؛ هیچ کد دورزدن مجوز یا فایل Pro در محصول نیست.

توسعه‌دهندهٔ افزونه: **Iman Shadmehri — https://elinweb.ir**. مجوز پروژه هنوز انتخاب نشده است؛ این سند مجوز جدیدی برای کد یا بازتوزیع دارایی‌ها اعطا نمی‌کند.
