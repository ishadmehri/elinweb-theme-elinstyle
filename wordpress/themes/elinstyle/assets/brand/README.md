# elinstyle — brand assets v1

لوگو با الهام از حرف e و گوشهٔ تاخوردهٔ لیبل لباس طراحی شده است. نشانهٔ هندسی با زیتونی مصوب و نوشتهٔ زغالی در نسخهٔ اصلی، برای پوشاک مدرن و روزمره در نظر گرفته شده است.

## فایل‌های آمادهٔ اتصال

- `logo.svg`: نشانهٔ زیتونی و wordmark زغالی روی زمینهٔ روشن؛ پس‌زمینه شفاف.
- `logo-light.svg`: نسخهٔ روشن برای زمینهٔ زغالی یا تیره؛ پس‌زمینه شفاف.
- `mark.svg`: نشانهٔ مستقل، بدون نوشته؛ برای زمینهٔ روشن.
- `favicon.svg`: نشانهٔ روشن روی کاشی زیتونی؛ خوانا روی هر دو زمینهٔ مرورگر.
- `brand-preview.png`: پیش‌نمایش واقعی ۱۰۰۰ × ۶۴۰؛ لوگو در ارتفاع‌های ۶۴ و ۳۲ و فاوآیکون در ۳۲ و ۱۶ پیکسل.

برای هدر از SVG اصلی با ارتفاع ۳۲ و عرض خودکار استفاده شود؛ نسبت بوم ۱۸۸٫۰۶ به ۴۲ و عرض نمایشی در ارتفاع ۳۲ حدود ۱۴۳٫۳ پیکسل است. SVG را کشیده یا فشرده نکنید. حداقل فضای آزاد پیشنهادی پیرامون لوگو ۸ پیکسل در این اندازه است. در کاربرد تصویری از نام جایگزین «elinstyle» استفاده شود؛ همهٔ SVGها title و role تصویری دارند. اگر لوگو پیوند خانه است، نام پیوند می‌تواند «elinstyle، صفحهٔ اصلی» باشد.

رنگ اصلی `#4D593C`، نوشته `#242622`، نسخهٔ روشن `#F7F5EF` است؛ رنگ جزئی تاخوردگی فقط برای تفکیک سطح لیبل استفاده شده است. این نسخه برای اندازهٔ هدر طراحی شده و ریزنوشته یا شعار ندارد.

نوشتهٔ lowercase از فایل واقعی `YekanBakh-Bold.ttf` به مسیرهای برداری تبدیل شده است. SVGهای نهایی هیچ text، فونت جاسازی‌شده، تصویر raster، اسکریپت یا مرجع خارجی ندارند. نام و هش فایل مبنا در `brand-evidence.json` ثبت شده‌اند؛ این کار مجوز جدیدی برای فونت انتخاب نمی‌کند.

منبع بازتولید `build-brand.py` است و `render-brand.cjs` فقط پیش‌نمایش تصویری را رندر می‌کند. خروجی واقعی Chromium مشاهده شد: حرف‌ها، فاصلهٔ نشانه و نوشته، نسخهٔ تیره و روشن و نشانهٔ ۱۶ پیکسلی قابل تشخیص‌اند. فایل‌های SVG نیز به‌عنوان XML بررسی شدند.

تغییرات این مأموریت فقط در همین پوشه انجام شده‌اند؛ آمادهٔ integration توسط فرانت‌اند هستند.

برای اجرای مولد، ELINSTYLE_BRAND_FONT را به فایل فونت مجاز خود تنظیم کنید. برای پیش‌نمایش، @playwright/test و Chromium لازم است؛ BROWSER_EXECUTABLE اختیاری است. این ابزارها در فرانت اجرا نمی‌شوند.
