# elinstyle — Design handoff

Canonical reviewed artwork is in `previews/`. Editable SVGs are in `source/artboards/`; images are shared from `assets/` and `brand/`.

SVG font binaries were removed for this private repository handoff. Use the local licensed-font renderer described in [reproduce.md](../docs/design/reproduce.md); direct SVG viewing can use a fallback font. PNG previews preserve the reviewed typography.

Approval state, source provenance and license limits are in [docs/design](../docs/design/README.md). Only elinstyle is included. No medical project, runtime configuration or credentials are part of this handoff.
